# Project

Read and follow the unified [teach](../teach/SKILL.md) skill with `mode: "project"`.

Project mode is **artifact-driven learning**: the learner builds something (code, essay, design, presentation) while developing independent ability. Define a small observable milestone and success rubric with the learner.

The learner *makes and explains* bounded parts — the AI does not produce the artifact for them. Ask the learner to predict or sketch an approach first. For each milestone, teach one governing idea with the standard technique loop, then have the learner build it independently.

An AI-written artifact, a passing build, or model praise is not independent learner performance. Seek external review when available via `ingest_external_evidence`. Require the learner to critique and revise based on feedback. Schedule delayed independent recreation with `schedule_review`.
